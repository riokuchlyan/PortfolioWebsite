# Rio Kuchlyan — Portfolio

Deployed at [riokuchlyan.com](https://riokuchlyan.com).

A personal portfolio built with Next.js, with a photography gallery at `/photography`.

- `app/page.tsx` — introduction, experience, portrait, and photography preview
- `components/SiteHeader.tsx` and `components/SiteFooter.tsx` — shared navigation and last-updated footer
- `app/photography/page.tsx` — photo gallery with a keyboard-accessible image viewer
- `data/profile.json` — name, links, contact
- `data/home.json` — introduction, experience rows, photography preview copy, and `lastUpdated` date (update this when site content changes)
- `data/gallery.json` — list of photos shown in the gallery, in display order
